# BifrostFM -- what is where, and who wrote it

BifrostFM is two programs built from this tree: an engine library in C
(`bifrost_engine.dll`) and the Windows program in C# that uses it
(`BifrostFM.exe`). Most of the tree is BifrostFM's own code; the engine
also builds in six open-source projects, each kept in a folder of its own
with its own copyright and licence. This file says which is which.

**BifrostFM's own code is copyright B. C. Services and licensed under the
GNU General Public License, version 2 or (at your option) any later version**
(the licence's text is `LICENSE`, and again beside the engine as
`engine\GPL-2.0.txt`). Every one of its
source files says so in its header. The open-source code keeps the copyright
and licence its own files state.

## BifrostFM's own code -- B. C. Services, GPL-2.0-or-later

| `gui\` | The program: the main window and its two panes, the copy and conflict windows, the partition and device windows, the filesystem check window, the properties windows, the text, hex and picture viewers and editors, the settings, and the engine's interface (`EngineNative.cs`, `EngineSession.cs`). Built by `engine\build_engine.bat`. |
| `engine\lwext4\src\ext4_inline.c`, `ext4_casefold.c` and their headers in `engine\lwext4\include\` | Inline-data and case-insensitive (casefold) directory support added to lwext4. |

| `tools\` | The tool that draws the icon and the About picture. |

`test_probe.in`, `test-resize` and `test_extent.*`); none of them is part
of the build.

### `engine\`

The engine, `bifrost_engine.dll`: BifrostFM's own C at the top of the
folder, compiled by `build_engine.bat` (gcc) together with the open-source
code in the sub-folders into one 64-bit DLL in `engine\out\`.

| File | What it holds, and what for |
|---|---|
| `bifrost_engine.h` | The engine's public interface, the one header a caller includes: every exported function, status code, flag and structure, with the contract each call keeps -- mirrored by hand in the program's `gui\EngineNative.cs` and `EngineSession.cs`, and guarded by an API version the program checks when it loads the DLL. |
| `bifrost_engine.c` | The engine's core: opening and closing an image or device (with the system-disk guard and volume locks; a range with no ext2/3/4 filesystem tried as FAT or exFAT), flushing, browsing and the simple edits (make, remove, a tree removed entry by entry, rename, permissions, owner, times, links), and the internals every other engine file shares -- the one-call-at-a-time gate (which keeps the ext-only calls off a FAT session), the error recorder, the path rules and their canonical form, and the directory reader. |
| `bfe_device.c`, `bfe_device.h` | The raw I/O beneath everything: opening a file or a real disk or volume and telling which it is, its size, sector, disk number and model; sector-aligned reads and writes; which disk Windows runs from; and locking and dismounting a disk's volumes before the disk is written. |
| `bfe_blockdev.c`, `bfe_blockdev.h` | The block device lwext4, the filesystem check and FatFs read and write through: an image file or a real disk presented as 512-byte blocks, with a device's sector alignment, the read-back that catches a card which does not keep its writes, and the read-only refusal. |

| `bfe_internal.h` | What the engine's own files share and export to nobody: the declarations of the core internals (`bifrost_engine.c`) and the text helpers (`bfe_util.c`), the shared constants, and the map of which function-name prefix belongs to which file. |
